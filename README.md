# Kora

Sistema de gestión y consulta de información nutricional.

## Descripción

Kora es un proyecto orientado a la gestión y consulta de información relacionada con alimentos y nutrición.

El sistema busca facilitar a los usuarios el acceso a información nutricional y proporcionar funcionalidades para la gestión del catálogo de alimentos.

## Estructura del proyecto

- `backend/` — Componentes del backend.
- `database/` — Recursos relacionados con las bases de datos.
- `postgres/` — Recursos relacionados con PostgreSQL.
- `mongodb/` — Recursos relacionados con MongoDB.
- `docs/` — Documentación del proyecto.
- `frontend/` — Aplicación frontend.
- `services/` — Servicios y microservicios del sistema.
